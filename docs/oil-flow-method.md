# 日本向け原油調達フロー 算出方法

対象データ: `data/oil-flow.json`
策定日: 2026-09-04 / 版: 2.0

このページは、当サイトが表示している「日本向け調達フロー（万BPD・隻/週）」の
算出根拠と計算式を公開するものです。第三者が同じ手順で再現・検証できることを目的としています。

---

## 2. 一次データ

| 項目 | 内容 |
|---|---|
| 出典 | 財務省 普通貿易統計「概況品別国別表 輸入」 |
| 取得元 | 政府統計の総合窓口（e-Stat）API v3.0 `getStatsData` |
| 概況品 | `30301` 原油及び粗油 |
| 取得値 | 相手国別・月別の輸入**数量**（単位: キロリットル） |
| 更新周期 | 月次。速報は翌月中旬ごろ公表 |

`data/oil-flow.json` の `source` フィールドに、実際に使用した統計表ID・対象月・取得日時を記録します。

### 出典の表示について

e-Stat の利用規約は政府標準利用規約（第2.0版）に準拠し、CC BY 4.0 International と互換です。
商用利用を含む二次利用が認められている一方、**出典の記載**と、
**加工した場合にその旨を明示すること**が条件とされています。

当サイトは取得した数量を換算・集計しているため「加工」に当たります。
そのため表示は次の形式で統一します。

```
出典：政府統計の総合窓口(e-Stat)（財務省 普通貿易統計）を加工して作成
```

加工の内容は本ページの4章（計算式）と3章（相手国からルートへの対応）がその全体です。
**当サイトの数値は政府が作成・公表したものではありません。**

## 3. 相手国からルートへの対応

公開統計で得られるのは**相手国**であり、**輸送経路**ではありません。
そのため以下の対応（`route_mapping`）を仮定として置いています。

| ルート | 対応する相手国 | 仮定の内容 |
|---|---|---|
| A（フジャイラ経由） | アラブ首長国連邦 | UAE 産原油は ADCOP パイプライン経由でフジャイラから積み出されているとみなす |
| B（インブー・東西パイプライン） | サウジアラビア | サウジ産原油は東西パイプライン経由で紅海側から積み出されているとみなす |
| C🇺🇸（米国） | アメリカ合衆国 | 仮定不要（相手国＝ルート） |
| C🌍（南半球） | ブラジル、ナイジェリア、アンゴラ | 仮定不要（相手国＝ルート） |
| 旧ルート（ホルムズ本線） | — | 手動値。封鎖状況の判断による |
| D（イラン通航料払い） | — | 手動値。封鎖状況の判断による |

### この仮定が成立する条件

**ホルムズ海峡の商業通航が停止していること。**

通航が停止している間は、UAE 産・サウジ産の原油が日本に届いていれば、
それは海峡を迂回する経路（ADCOP／東西パイプライン）を通ったものと考えられます。
**海峡の通航が再開した場合、この仮定は成立しなくなります。** その時点で対応表の見直しが必要です。

### 対応表に載らない相手国

カタール・クウェート・イラク等、ホルムズ海峡の内側から積み出す産油国は、
封鎖下ではいずれのルートにも割り当てられません。
これらの輸入量が 0 でない場合、`_audit.unmapped_bpd` に合計して記録し、
どのルートにも計上しません（実態と仮定のズレを可視化するため）。

## 4. 計算式

### 4-1. 数量（万BPD）

```
bpd[万BPD] = 輸入数量[kL] × 6.28981[bbl/kL] ÷ 当月日数[日] ÷ 10,000
```

- `6.28981` は 1 キロリットルあたりのバレル数（API 標準の換算係数）
- 「当月日数」は対象月の実日数（28〜31）
- 小数第1位を四捨五入して整数にします（表示が整数のため）

### 4-2. 隻数（隻/週）

```
tankers_week[隻/週] = bpd[万BPD] × 10,000 × 7[日] ÷ 2,000,000[bbl/隻]
```

- `2,000,000 bbl/隻` は VLCC（大型原油タンカー、30万重量トン級）1隻あたりの標準積載量
- 小数第1位を四捨五入して整数にします

**この値は実際の寄港隻数ではありません。** その供給量を運ぶために必要な
VLCC 換算の理論隻数です。実運用では船型が混在するため、実隻数はこれより多くなります。

### 4-3. 平常時総量（`normal_total_bpd`）

ホルムズ海峡封鎖前の直近12か月の原油輸入総量から、同じ式で日量換算した平均値。
年1回、または封鎖前期間の定義を変更したときに更新します。

## 5. 自動更新と鮮度

| 項目 | 内容 |
|---|---|
| 実行 | GitHub Actions `update_oil_flow.yml`。毎月20日 09:00 JST（貿易統計の速報公表後） |
| 手動実行 | `workflow_dispatch` で随時可能 |
| 鮮度判定 | `updated_iso` からの経過日数が `stale_after_days`（既定 45 日）を超えると、表示側に警告を出します |

**週1回の更新は行いません。** 裏づけとなる公開統計が月次であり、
週次で更新しても新しい一次情報が得られないためです。
大きな事件が起きた場合は、手動値（`old` / `D`）と `note` を臨時に更新します。

---

## 6. 手動判断が残る部分

すべてを自動化しているわけではありません。以下は人の判断です。

| 項目 | 内容 |
|---|---|
| `routes.old.bpd` / `routes.D.bpd` | 封鎖状況の判断。統計から分離できないため現状 0 固定 |
| `route_mapping` | 相手国とルートの対応。封鎖状況が変われば見直しが必要 |
| `note` | 各ルートの状況説明 |

`data/oil-flow.json` の各ルートには `derivation` フィールドがあり、
`"estimated_from_trade_statistics"`（自動算出）か `"manual"`（手動値）かを示します。

## 7. 既知の限界

1. **統計のラグ。** 貿易統計の速報は対象月の翌月中旬に出るため、表示値は最大で約1.5か月前の実績です
2. **経路が推定であること。** 3章の仮定に依存します。統計そのものは経路を持ちません
3. **隻数は理論値であること。** 4-2 のとおり実隻数ではありません
4. **積み替えを追えないこと。** 第三国での積み替えがあった場合、貿易統計上の相手国と実際の産地・経路が一致しない場合があります
5. **一次データの提供が変わりうること。** e-Stat API機能利用規約は、利用者への事前の通知なく機能の停止・仕様変更を行えると定めています（第5条2項）。また負荷状況に応じたアクセス制限（同3項）や、統計表IDの年次改編もあり得ます。これらが起きた場合、月次の自動更新は停止します
6. **提供元が内容を保証していないこと。** 同規約第10条により、e-Stat のコンテンツの完全性・有用性は保証されていません。当サイトの数値も同様に、正確性を保証するものではありません

### 自動更新が止まった場合

`data/oil-flow.json` の `updated_iso` からの経過日数が `stale_after_days`（既定 45 日）を
超えると、ダッシュボード上に警告を表示します。
古い値を最新のものとして表示し続けることを避けるための仕組みです。
