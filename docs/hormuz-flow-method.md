# ホルムズ海峡の通航数・石油流量 算出方法

対象データ: `data/portwatch-hormuz.json`・`data/context.json`
策定日: 2026-10-26 / 版: 2.0

このページは、当サイトのダッシュボードが表示している「日次通航数（7日平均）」と
「ホルムズ通過石油 AIS で見えた流量」の算出根拠と計算式を公開するものです。
第三者が同じ手順で再現・検証できることを目的としています。

---

## 1. 版の履歴と、旧版との違い

| 版 | 期間 | 算出方法 |
|---|---|---|
| 1.0 | 2026-04-15 〜 2.0 の公開日 | **生成AI（2026-10-24 まで Gemini、10-25 から Claude）がニュースの見出しと短い説明文から推計した値。** 通航数・流量・供給途絶率とも AI の出力をそのまま表示していました |
| 2.0 | 2.0 の公開日 〜 | IMF PortWatch の日次通航（AIS の集計）から機械的に算出。AI は使いません |

**版 2.0 への切り替えにより数値は大きく変わります。** これは実態の変化ではなく算出方法の変更によるものです。
例として 2026-10-25 の表示は、版 1.0 が 8.0 百万バレル/日（供給途絶 62%）、版 2.0 が約 0.11 百万バレル/日（平常時の 0.5%）でした。
版 1.0 の流量は、AIS の実測とも、報道（「通航が95%減」Al Jazeera・2026-08-27）とも1桁合わず、過大だったとみています（確度：中）。
両者を時系列で連続したものとして比較しないでください。

## 2. 一次データ

| 項目 | 内容 |
|---|---|
| 出典 | IMF PortWatch「Daily Chokepoint Transit Calls and Trade Volume Estimates」 |
| 取得元 | ArcGIS Feature Service `Daily_Chokepoints_Data`（`portid = chokepoint6`・Strait of Hormuz）。キー不要 |
| 取得値 | 日別の通航数（`n_total`・`n_tanker`・`n_cargo`）とタンカーの積載量（`capacity_tanker`・トン） |
| 通航の定義 | 船が海峡の境界を越えたら1回。同じ船は 48時間あけてから再び数える。対象はコンテナ・ばら積み・一般貨物・RoRo・タンカーの5種類だけ |
| 積載量 | PortWatch が船の寸法・喫水・載貨重量トンから推定した値（IMF Working Paper No. 2021/225） |
| 更新周期 | 約1週間遅れで、週1回まとめて入るとみられます（曜日は観察中）。当サイトは毎日 10:43 JST に取りにいき、新しい行があったときだけ更新します |
| 取得の処理 | `scripts/fetch_portwatch.py`（`.github/workflows/update_portwatch.yml`） |

### 出典の表示について

IMF のデータの利用条件（https://www.imf.org/external/terms.htm）は、出典の明示と、加工した場合にその旨を書くことを求めています。
当サイトでは「出典：IMF PortWatch（International Monetary Fund）を加工して作成」と表示します。

## 3. 計算式

日付はすべて UTC の暦日です。「直近7日」は PortWatch に入っている最新の日（`latest_date`）から遡った7日で、今日からではありません。

### 3-1. 日次通航数（カード1）

```
日次通航数 = 直近7日の n_total の平均
2025年平均比 = 日次通航数 ÷ 85.5（PortWatch の 2025年の n_total の平均）
```

- 日ごとの揺れ（0〜7隻）が大きいため、主な値は7日平均にしています。最新日の値は別に添えます
- 分母は分子と同じ出典にそろえています。報道でよく見る「100隻超/日」は船種の範囲が違うため使いません
- 2026年1〜2月（開戦前・68.1隻/日）は、すでに緊張の高まりが入っているとみて分母に使いません

### 3-2. AIS で見えた石油流量（カード2）

```
AIS で見えた流量 = 平常時流量 × （直近7日のタンカー積載量の平均 ÷ 2025年上半期のタンカー積載量の平均）
平常時流量 = 20.9 百万バレル/日（EIA World Oil Transit Chokepoints・2025年上半期）
```

**比の分母を 2025年上半期にした理由**：平常時流量 20.9 が EIA の 2025年上半期の値なので、積載量の期もそろえました。
2025年通年（2,253千トン/日）を使うと結果は約3%大きくなります（2026-10-18 までの7日で 0.112 → 0.116）。

**積載量の比をそのまま流量の比とみなせる根拠**：2025年上半期の PortWatch のタンカー積載量は 2,330千トン/日で、
原油・製品をまとめた換算（1トン ≒ 9.0バレル）では約 21.0 百万バレル/日となり、EIA の同期の 20.9 とほぼ一致します。

2026-10-12〜18 の例：

| 項目 | 値 |
|---|---|
| 直近7日のタンカー積載量の平均 | 12,526 トン/日 |
| 2025年上半期のタンカー積載量の平均 | 2,329,877 トン/日 |
| 比 | 0.54% |
| AIS で見えた流量 | 20.9 × 0.0054 ≒ **0.11 百万バレル/日** |

## 4. 下限であること（ダークシッピング）

PortWatch は AIS（船舶自動識別装置）の受信に基づくため、**AIS を切った船は数えられません**。
表示している通航数・流量は、どちらも「AIS で見えた分」の下限です。

追跡できない割合の報道値（Lloyd's List Intelligence：2026-07-20〜26 の週に全船種の約7割）はカードに文章で示しますが、数値には掛けません。
割合は週ごとに大きく動き（直前3週で 42% → 55% → 70%）、1つの係数で割り戻すと誤差を隠すためです。
版 1.0 で使っていた補正係数 1.35 は、導出の記録がなく、2026-10-26 から使っていません。

## 5. 自動更新と鮮度

| 状態 | 表示 |
|---|---|
| 最新の行が 14日以内 | 「実測（AIS で捕捉した分・下限）」 |
| 最新の行が 14日より古い | 「取得が止まっています」と注意書き（値は最後に取れたものを残す） |
| ファイルが読めない | 「データ取得不可」。**AI 推計では埋めません** |

週1回の更新なので、最新の行が 7〜13日前なのは平常です。

## 6. 既知の限界

- **積載量が 0 の日**：PortWatch は、タンカーの通航があっても積載量を 0 で返す日があります（2026-10-15 など）。0 のまま平均に入れるので、その日を含む週は流量が低めに出ます。カードに日数を注記します
- **換算の前提**：積載量の比を流量の比とみなすのは、原油と製品の比率や積載率が 2025年上半期と大きく変わらない前提です。封鎖下で船の構成が変わっていれば外れます（未確認）
- **船種の範囲**：5船種以外（漁船・旅客船・タグボートなど）は含みません。ガス運搬船がどの船種に入るかは確かめていません
- **遅れ**：約1週間遅れのため、速報には向きません。日々の動きは `/hormuz/` の日次（UKMTO など）を見てください
