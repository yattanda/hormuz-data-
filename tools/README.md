# tools/ — 診断・検証スクリプト

本番の自動更新には**関与しない**、手元で実行する調査用スクリプト置き場。
`.github/workflows/` からは呼ばれない。

## 収録スクリプト

| ファイル | 用途 | 終了コードで結論が出る |
|---|---|---|
| `diag_ais.py` | AISstream.io の疎通診断。ホルムズ bbox と全世界 bbox の対照実験 | 0=正常 / 10=bbox・カバレッジ問題 / 20=サービス側 / 30=接続・認証 |
| `diag_ais_coverage.py` | 全世界 bbox で受信し、**地理的に集計してカバレッジの実在を判定** | 0=ホルムズで受信 / 10=中東圏で受信 / 20=中東が完全空白 / 30=接続・認証 |
| `diag_gfw.py` | Global Fishing Watch API がホルムズの通航船を返すかの実現可能性検証 | 0=検出できた / 10=0件 / 20=認証 / 30=パラメータ不正 |

いずれも**読み取り専用**（ファイルを書かない）。API キーは環境変数から読む。ハードコードしない。

## なぜ残してあるか

2026-09-01 の調査で、AISstream.io に**ペルシャ湾・ホルムズ海峡の受信局カバレッジが存在しない**ことが判明した
（全世界 bbox は60秒で3,467隻、ホルムズ bbox は180秒で0隻。最寄りの受信船まで約1,900km）。
この状態のまま 2026-04-15 から約4.5か月、`vessels_detected: 0` を書き続けていた。

**契約・実装の前にカバレッジを実測する**という手順を踏んでいれば防げた失敗であり、
`diag_ais_coverage.py` の手法（全世界受信 → 地理的集計）は次のデータソース選定で再利用できる。

新しい AIS ソースを検討する際は、**必ず無料枠・トライアルの範囲でホルムズ bbox の実測を行ってから**契約すること。

## AIS データソース選定メモ（2026-09-03 時点・未確定）

### 満たすべき要件

1. **ホルムズ海峡／ペルシャ湾の実カバレッジ**（地上 AIS だけでは届かない。衛星 AIS またはそれに準ずる補完が要る）
2. **「取得成功かつ0隻」と「取得失敗」をレスポンスから区別できること**
   （AISstream.io は WebSocket ストリーム型のため両者が同じ `0 / 0` になり区別不能だった。
   REST 型 API なら HTTP ステータス＋空配列で区別できる見込み。確度：高／未実測）
3. **日次1回の取得で足りる**（現行 cron は日次。リアルタイム性は要件外）
4. **公開サイトでの表示が利用規約上許されること**（ここが最大の制約）

### 候補と調査結果

| 候補 | 価格 | 衛星カバレッジ | 無料枠 | 備考 |
|---|---|---|---|---|
| AISstream.io | 無料 | なし（地上のみ） | あり | **ペルシャ湾カバレッジ無しを実測で確認。不適合** |
| Global Fishing Watch | 無料 | あり | あり | **96時間遅延・CC BY-NC 4.0（非商用限定）で不適合** |
| AISHub | 無料 | 会員の地上局に依存 | 条件付き | 原則として**自局のデータ提供が会員条件**。中東局の有無は未確認 |
| Data Docked | €80/月〜 | 衛星＋地上を標榜 | 20クレジットの無料トライアル | **最安。トライアルでカバレッジ実測が可能**。規約は未確認 |
| Datalastic | €199/月（Starter） | 標準プランは地上中心。衛星推定は**アドオン扱い** | €9 の14日トライアル | 規約に生データの公開表示禁止条項あり（下記） |
| VesselFinder | €330〜（10,000クレジット） | 衛星＋地上 | なし | 単価が高い |
| MarineTraffic | 要商談（クレジット制を廃止） | 衛星＋地上 | なし | Kpler 傘下。個人媒体には重い |
| Spire Maritime | $2,000〜8,000/月 | あり | なし | 予算外 |

### ライセンス上の注意（重要）

Datalastic の利用規約は、**生データ・API レスポンスをそのままの形で公開アプリケーションに表示すること**を禁じている。
一方で、**分析・可視化・ダッシュボード等の付加価値プロダクトの作成は認められている**（生データを露出させず、
サービスの代替として機能しない限り）。

当サイトの用途は個船情報ではなく**通航隻数の集計値の表示**であるため、許容範囲に入る可能性が高いが、
**これは条文の解釈であり確定ではない。契約前に提供元へ書面で確認すること**（確度：中）。
同種の条項は他の商用プロバイダにも存在するのが通例のため、候補ごとに同じ確認が要る。

### 次のアクション（推奨）

1. Data Docked の無料トライアル（20クレジット）でホルムズ bbox を叩き、**実際に船が返るかを実測**する
2. 同時に、集計値の公開表示が規約上許されるかを提供元に確認する
3. 1・2 が両方通れば €80/月で実測ソースを確保できる。通らなければ Datalastic の €9 トライアルで同じ検証を行う
4. いずれも不可なら、**AIS 実測は当面断念し「AI 推計のみ・出自を明示して運用」を正式な方針として確定**する

※ 実測ソースの有無は、推計と実測の分離設計（`data/ais-snapshot.json` / `data/ais-estimate.json` の2ファイル化）の
論点「実測0隻をどう扱うか」の前提になる。詳細は `hormuz-map/.claude/handovers/2026-09-03_1430.md` を参照。
